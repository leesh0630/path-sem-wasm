06목표 기반 다중 제외 조합 탐색


자동 삭제 권고가 아니라 민감도 분석 후보입니다. 목표 달성을 이유로 표본을 삭제하면 선택 편향이 생길 수 있습니다. 탐색 결과는 원자료와 함께 보고하세요. 목표 미달은 “탐색한 범위에서 미발견”이며 불가능하다는 뜻이 아닙니다.


아래 목표는 04의 좋은 방향과 별도입니다. 목표 1 → 2 → …의 미달량을 우선 최소화하고, 모두 동점이면 실행 당시 04 우선순위를 적용합니다. 목표를 초과 달성한 정도는 미달량 0으로 같습니다. 전체 목표를 충족한 조합은 미충족 조합보다 앞섭니다.




















총 제외 수는 정확히 k명입니다. 결측으로 이미 제외된 사례는 지정할 수 없습니다. 현재 05 시나리오는 자동으로 고정하지 않습니다. 필요하면 고정 제외란에 직접 입력하세요. 원본 행 번호는 헤더·빈 레코드를 제외한 데이터 순서입니다.




순서목표 지표 (최대 10개)조건목표값± 허용오차




조건: ≥ 이상 / ≤ 이하 / 목표 ± 오차. ≥·≤에는 허용오차를 적용하지 않습니다. CI가 양수인 조건은 ‘하한 ≥ 원하는 양수’, 음수인 조건은 ‘상한 ≤ 원하는 음수’로 설정하세요. p ≤ 0.05와 p < 0.05는 다릅니다.







기본분석 후 목표를 선택하세요.






조합 탐색 이력 · 이전 실행 설정과 평가 기록


전수 탐색만 해당 후보 범위의 모든 조합을 평가합니다. 빔 탐색은 일부 유망한 부분집합만 확장하므로 전역 최적해·목표 발견을 보장하지 않습니다. 중간 단계가 부적절한 해이면 그 가지는 확장하지 않아, 정상적인 최종 조합을 놓칠 수도 있습니다. 각 후보는 단일 제외 효과를 합산하지 않고 lavaan으로 다시 추정합니다.





사용 범위 · 실행 환경 · 해석 주의사항


① CSV/TSV, 연속형 수치 관측변수, 단일집단 ML만 지원합니다. Excel/SPSS 파일은 CSV로 변환하세요. 잠재변인별 단순 측정모형과 재귀 구조모형을 지원합니다. 교차적재·지표 잔차상관·단일/2지표 잠재변인·다층·범주형 전용 추정·가중치·군집 표준오차·MLR/WLSMV는 지원하지 않습니다.

② UTF-8 또는 EUC-KR를 선택하고 다시 파일을 여세요. 빈칸, NA, N/A, NaN, NULL은 결측입니다. 999 같은 사용자 결측 코드는 업로드 전 변환하세요. 숫자 안의 천 단위 쉼표·소수점 쉼표는 지원하지 않습니다.

③ 원자료는 앱 코드에서 외부로 전송하지 않고 브라우저 메모리와 webR 가상 파일시스템에서 처리합니다. 다만 엔진/패키지를 내려받는 외부 요청은 발생합니다. 내보낸 파일에는 사례 ID·제외 이력 등이 포함될 수 있습니다.

④ 더블클릭(file://)은 브라우저 정책에 따라 실패할 수 있습니다. 권장: HTML 폴더에서 python -m http.server 8000 --bind 127.0.0.1 실행 후 로컬 주소에서 여세요. 별도 R 서버는 필요 없습니다. 인터넷과 Wasm/Worker 지원 브라우저가 필요합니다.

⑤ GFI/AGFI는 전통 LISREL 정의를 사용합니다(신규 lavaan에서는 gfi_lisrel/agfi_lisrel 자동 매핑). 일반 CI는 간접효과의 비정규성을 완전히 반영하지 않습니다. 표본선택 후 p값/CI를 확증적 결과로 해석하지 마세요. 표본 감소 자체가 χ²·p에 영향을 주며, 서로 다른 사례집합의 AIC/BIC를 같은 데이터의 모형 비교처럼 해석하지 마세요. 카이제곱의 p값 상승은 좋은 모형의 충분조건이 아니고, GFI/AGFI나 고정된 지수 절단값만으로 결론내리지 마세요.

⑥ 현재 사례 추정은 즉시 중단하지 않고 끝난 후 멈춥니다. 대규모 사례/모형은 오래 걸리고, 간접경로가 2,000개를 넘으면 생성을 차단합니다. 새로고침하면 데이터·결과가 사라지므로 먼저 내보내세요. 다중 제외는 실행당 최대 5,000회 추정하며 반복 탐색 이력은 메모리를 사용합니다. 장시간 사용 후 JSON을 저장하세요.
